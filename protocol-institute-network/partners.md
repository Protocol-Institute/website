# Protocol Institute Network — Member Data

This file is the source of truth for the network page (`network.html`).

**To add a member:** Add a new `## Org Name` block below following the template. Drop the logo in this folder using an org slug as the filename (e.g., `nyu-shanghai.png`). Then ask Claude to sync `network.html`.

**Template:**
```
## Full Unit Name, Parent Organization

**Contact:** [Name](https://personal-page-url), Title
**Website:** https://... (optional)

![Logo](./slug.png)   ← omit if no logo yet
```
Name can be any of: `First Last`, `Prof. First Last`, `Dr. First Last`, etc.
Title (`, Title`) is optional — omit if the name alone is sufficient.
If no link yet, omit the brackets: `**Contact:** Prof. First Last`

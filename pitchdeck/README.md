# Protocol Institute — Support Deck

This is a collectively authored and maintained presentation to help seek support for the Protocol Institute. It outlines who we are, what we do, and how donors and partners can engage with our work.

The deck is embedded on [protocol-institute.org/support.html](https://protocol-institute.org/support.html) and can also be viewed directly at [protocol-institute.org/pitchdeck/deck.html](https://protocol-institute.org/pitchdeck/deck.html).

## Contributing

Suggestions, edits, and additions are welcome. If you have ideas for improving the framing, updating the content, or adding new material, please open a pull request or file an issue.

Content lives in the `<script id="deck-content">` block inside [`deck.html`](deck.html). See [`EDITING.md`](EDITING.md) for a full guide to slide types and the editing workflow.

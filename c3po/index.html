C3PO

C3PO is the Protocol Institute's research assistant — a retrieval-augmented AI that makes the full PI corpus conversationally accessible. Ask it a question about protocol theory, a specific paper, a design problem, or a cross-domain connection, and it will draw on the corpus to respond — with citations. Try it →

The corpus spans ~26,000 indexed passages across ten namespaces: the Protocolized PDF library (82 papers and essays), the Protocolized Substack archive (117+ posts), Protocol Institute Discord discussions and SIG meeting records, video transcripts from 91 talks, community-shared links, and the PI protocol lexicon. The majority of the primary material originated in the Summer of Protocols program (2023–2024); the corpus grows continuously as new content is published and ingested.

What C3PO does

C3PO is a RAG (retrieval-augmented generation) system. When you ask a question, it searches the embedded corpus for the most relevant passages across all ten namespaces simultaneously, then generates a response grounded in those sources. It always cites what it found. It does not answer questions outside the corpus, and it is transparent about the limits of what it knows.

Intended uses include:

  • Finding relevant research on a specific protocol domain (medical, diplomatic, software, financial, urban, ecological)
  • Synthesizing what the corpus says about a theoretical question (hardness, formalization, enforcement, capture, protocolization)
  • Discovering connections across papers and disciplines that are hard to find by browsing alone
  • Getting oriented in the literature before diving into primary sources
  • Looking up PI-coined terms and concepts — the lexicon is part of the index

Where to find C3PO

Web: c3po.protocolized.io — the primary interface. Full research-librarian voice: substantive, source-specific, 3–5 paragraphs. Rate-limited; no account required.

Discord: C3PO is active in the PI Discord server. @mention it in any channel to open a research thread, continue for up to five turns, or use the /ask slash command. The Discord bot uses a shorter, more direct voice suited to conversation — it also monitors #introductions to welcome new members with relevant reading recommendations.

MCP server: C3PO exposes a Model Context Protocol endpoint at c3po.protocolized.io/mcp, letting Claude Code, Claude Desktop, and other MCP-compatible clients search the corpus and ask questions directly from an AI coding environment. See the how it works page for connection instructions.

Technical approach

C3PO uses Voyage AI embeddings (voyage-3, 1024 dimensions), Pinecone as the vector store, and Claude Sonnet as the language model. The system runs as a Cloudflare Worker serving a web UI, a rate-limited REST API, an MCP endpoint, and a Discord slash-command handler from a single deployment. A Python ingest daemon runs locally on a 30-minute cycle, keeping the corpus current as new Discord discussions, SIG meetings, Substack posts, and shared links are published.

The source code is at github.com/Protocol-Institute/c3po.

# Protocol Institute Consulting — Directory

This file is the source of truth for the consulting page (`consulting.html`).
Members are listed alphabetically by last name.

**To add a consultant:** Add a new `## First Last` block following the template.
Drop a square headshot image (at least 240×240px) into this folder using the
person's name slug as the filename (e.g., `jane-smith.jpg`). Then ask Claude
to sync `consulting.html`.

**Template:**
```
## First Last

**Role:** Title or affiliation
**Expertise:** Area 1 · Area 2 · Area 3
**Contact:** [email or name](mailto:... or https://...)
**Photo:** filename.jpg   ← in this folder; omit if no photo yet
```

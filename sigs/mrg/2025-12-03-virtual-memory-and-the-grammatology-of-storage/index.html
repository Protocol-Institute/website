Virtual Memory and the Grammatology of Storage

Virtual memory metaphors and computational storageMatthew Kirschenbaum's 'Extreme Inscription' frameworkPreposition choice in describing memory operations (e.g., 'writing to')Memory differences between traditional databases and LLMsLLM memory as transformative versus retrievable storageNarrativization of memory in language models

Participants: keikreutler, thewanderingeditor, ruthvik8193

The Memory Research Group examined virtual memory through the lens of Matthew Kirschenbaum's "Extreme Inscription," investigating how metaphorical language—particularly the preposition "to" in "writing to" storage devices—shapes our understanding of computational memory. The group explored how this metaphor implies permanence and retrievability while masking the actual physical and logical processes of data storage.

A central distinction emerged between traditional database memory and Large Language Model memory. Whereas databases store and retrieve information discretely, LLMs appear to assimilate information into larger structures that transform what is stored in unpredictable and fundamentally different ways. The group concluded that LLMs perform a significant translation from database operations into narrativized memory—a form humans recognize and find meaningful—yet this narrativization occurs through computational processes that remain alien and mysterious to human understanding.

  • The metaphor of 'writing to' hard drives connects computational processes to traditional writing, suggesting permanence and retrievability that may not accurately describe how systems actually store information.
  • LLM memory operates fundamentally differently from database storage—information appears to be assimilated into an organic structure that transforms stored data in unpredictable ways rather than simply retrieving it.
  • LLMs perform a meaningful transformation from raw database operations into narrativized memory that humans recognize and find meaningful, despite operating through alien computational processes.
  • Language choice in describing storage systems carries significant implications for how we conceptualize memory and computational processes.

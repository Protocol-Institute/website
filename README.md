# Protocol Institute Website

The public website for the [Protocol Institute](https://protocol-institute.org), an independent research organization focused on protocol technologies.

## About the site

Plain HTML, CSS, and JavaScript. No build step, no framework, no dependencies. Edit files and push — Cloudflare Pages deploys automatically from the `main` branch.

## Pages

| File | Page |
|------|------|
| `index.html` | Landing page |
| `about.html` | About the Institute |
| `projects.html` | Initiatives |
| `sigs.html` | Special Interest Groups |
| `worldbuilding.html` | Worldbuilding (stub) |
| `contact.html` | Contact |

## Contributing

Pull requests are welcome. For significant changes, open an issue first.

If you are using an LLM to assist with edits, see `CLAUDE.md` for codebase conventions, design patterns, and guidance on adding pages or initiatives.

A few things to keep in mind:
- Match the tone and visual style of existing pages
- Do not introduce frameworks, build tools, or external dependencies
- Keep the single stylesheet (`css/style.css`) as the source of truth for all styles
- Test pages by opening them directly in a browser — no server needed
